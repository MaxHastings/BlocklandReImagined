## Release integration and adversarial review

Maxwell expanded this pass to include the v0.2.2 foundations and recurring
failure patterns, rather than only the listed reports. A fresh GPT-6.1 Sol High
review checks live authority during sliced jobs, support and object identity
freshness, bounded work on unusual authored geometry, predictor rollback and
rendered crossing frames. Related creator menus, content and documentation are
part of the cohesion review. Concrete faults justify narrow architectural
corrections; this does not promise that every subsystem or experimental design
is complete.

The independent review already found stale captured actor/trust and support
information in older sliced duplicator jobs, and amplification risks in proposed
map-connector and face-coverage checks. Those are integration blockers until
corrected with real entry-point regressions and reviewed again. Test counts from
earlier direct API fixtures do not close a missing user command path.

Root owns final source integration, full content-backed gate, Windows CI, the
immutable release tag and all three staged archives. Publish the draft only
after checking the archives and workflows. Preserve failed evidence and clearly
identify unreproduced reports; do not label diagnostic improvements as causal
fixes. The Rule Workshop and bounded bot planner remain alpha experiments.
