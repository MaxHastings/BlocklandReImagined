# Building simulation integration

`bri-sim` combines native content, world authority and Rapier. It contains no
Torque reader and serves both local and network sessions.

## Rules implemented

- Integer placement uses half-unit horizontal studs and 0.2-unit vertical plates.
  BLB occupancy/attachment rows rotate with each placement. Empty ramp/corner
  cells remain empty; vertical studs/undersides determine connections independently
  of the collision hull and visible faces. Eight-unit spatial buckets avoid
  expanding every placed brick into a separate voxel collection.
- The authority validates placement before changing IDs, revisions or world state.
  It rejects off-grid, out-of-reach, overlapping and unsupported placement, and
  attachment to bricks whose owner does not give the builder build trust
  (v20 `$TrustLevel::BuildOn`). World-owned support and administrator support
  are allowed.
- Map collision uses native interiors and terrain. Ground support tolerates a
  grid-snapped gap of up to one plate; this remains a fidelity assumption for
  Maxwell to assess. Moving/kinematic entities prevent penetrating placement.
- Authored collision occasionally extends below the logical build grid: the
  pine tree's lowest hull vertex is -2.2145438 against a -2.2 logical bottom.
  At an upward map contact, placement permits exactly this derived below-grid
  extent plus the existing 0.002 numeric contact tolerance. The hull remains
  unchanged for physics. Moving entities do not receive this allowance.
- Targeting queries nearby bricks against their precise authored convex planes.
  Map surfaces occlude targets. Raycast, visible and colliding flags are separate;
  non-colliding bricks use sensor colliders and can remain selectable.
- Delayed collision events update the solver, and removal releases both the
  collider and build index. A test rests a body on a brick, activates a delayed
  collision event, and verifies it drops onto the underlying floor.
- Body-facing shifts implement stud/plate increments and footprint-size
  super shifts. Quarter turns adjust odd/even footprint parity to preserve the
  grid. The audit corrected the earlier claim about incomplete rotation branches:
  they are complete and include an identity case. The current symmetric anchor
  correction is still an assumption. Resolve original engine transform snapping
  before claiming equivalent rotation. Four turns currently restore the center.
  Input routing must pass body heading, including while the camera free-looks.

## Evidence

`artifacts/native-building/integration.json` is generated by:

```powershell
cargo run -p bri-sim --release --bin building_probe -- content/stock-catalog-003 content/maps-pass-003 content/worlds-pass-003 content/map-bundle-005 artifacts/native-building/integration.json
```

The current run loads all 35 converted worlds (276,612 placements) into the
integer build index and Rapier with one collider per placed brick and shared
cooked templates. All 145 definitions resolve. It checks 564 plant/remove cases
(141 definitions in four orientations) against a fixture floor. The four water
definitions remain listed as requiring native behavior adapters and are not
silently treated as ordinary solid bricks.

The probe also plants, targets, rejects overlap, removes and replants a stock
1x1 near each original Bedroom, Kitchen and Slopes spawn using native map
collision. The Slopes footprint samples its corners before snapping upward so
the terrain cannot rise into the brick unnoticed.

The release run on this Windows/Ryzen 7800X3D machine took about 2.42 seconds.
Golden Gate Bridge's 44,465 placements loaded with collision/index in about
118 ms. These are one-run warm-cache CPU integration timings, including native
world parsing; they are not frame-rate, networking, rendering or memory results.

Seven simulation tests cover rotated authored voids/connections, shifts, atomic
placement failure, support/ownership/reach, entity obstruction, triangle-map
occlusion, independent flags, delayed solver updates and the below-grid hull
allowance. That milestone passed 42 workspace tests and all-target Clippy
with warnings denied.

## Audit follow-up and expanded catalog

`content/stock-catalog-004` resolves 170 definitions and native collision bodies:
the original 145 plus Arch 12, V15 4, Halloween 5, Treasure Chest 2, Checkpoint 1 and
Teledoor 1. Four are hidden states, leaving 166 selector entries. Selector code
must use `CatalogEntry::selectable()`; retain hidden definitions for state changes.
The BLS name table uses last declaration wins, matching source line 2608. Both
treasure states share a name and saves load the closed state. A regression covers
this and empty icon names; the audit records the alias explicitly.

`python tools/regenerate_content.py` rebuilds it (`docs/content-regeneration.md`)
with the `stock_catalog` converter. It reads enabled Brick_* entries from the recovered stock
default add-on list as data, preserving list order and rejecting missing archives.

`artifacts/native-building/stock-defaults.json` checks 644 plant/remove cases
(161 definitions in four orientations), all 35 worlds/276,612 bricks and the three
native map spawns. Nine definitions explicitly require gameplay adapters: four
water variants, Pumpkin, both treasure states, Checkpoint and Teledoor. Successful
geometry conversion does not claim their behavior is implemented. The independent
BLS verifier passes again using the expanded catalog.

The expanded authored-surface collision probe passes 61,710 precise ray comparisons
over 170 bodies, maximum error 0.0002248. It separately reports 22 GJK coverage
differences; the authored-plane targeting path remains in use. The imported round
brick solver-contact check passes (`artifacts/native-collision/stock-defaults.json`).

## Remaining integration and fidelity work

- Player motor, server-created interaction context, socket commands and native
  client input routing exist; see `player-simulation.md`, `networking.md` and
  `native-client.md`.
- Rooted-build connectivity and original removal behavior. Physical player
  touch-entry feeds the event scheduler. Tool rays use the audit's distances.
  Atomic ordinary wrench properties, inspection races, print compatibility,
  planting undo and trust levels are implemented.
- Water bricks are liquid volumes in the simulation. Checkpoint, Teledoor,
  treasure chest and Pumpkin behavior is in `crates/sim/src/session/special.rs`.
  Native map loading reports pending scene objects: 16 Bedroom, 25 Kitchen,
  one Slopes entry in the current bundles. These are not complete maps yet.
- Terrain collision streams tiles around every moving body plus authored spawn
  anchors (`TerrainStream` in `crates/sim/src/map.rs`).
- Native client ghost placement is connected, including non-grid map-floor
  placement. Exact original anchoring/rotation and terrain-only bias remain open.
- Client building/tool integration is verified through typed UI actions, real
  QUIC authority and offscreen rendering. Exact feel remains to be judged in
  playtests.
