# v0.1.11: definition of done (proposed 2026-10-01, defaults until Max says otherwise)

v0.1.11 ships when every line below is true on one final main commit. Each line
names how it is checked. Nothing here overrides an earlier Max rule; it collects them.

## Content
1. **Every lane is in.** Each lane's work has landed on main through the Gate, or
   has been dropped by Max. Nothing is "almost in".
2. **The originals are real.** Each bundled original is imported and ported from
   Max's PC copy, and `ports[].applied` is true on the real copy. Credits are in
   CREDITS.md. Defaults: Duplicator on, Stunt Plane on, Mirror on, New Duplicator
   off, the rest installed but off. The repo holds no third-party, v20 or derived
   files (the gate's blob check plus a review of the bundle list).
3. **Every bundled Add-On does its main job** in a content test on the PC: a gun
   fires and hurts, a tool does its thing, a mode starts and scores. That is one
   targeted test per Add-On, not a playtest.

## Code
4. **The app.rs split is on main, last** (Code health), plus the final structural
   batch: script ops, messages and hooks registered per feature; one default
   Add-On list; the modding guide split by topic; progress notes one file each;
   protocol change files; one rustfmt commit with a CI fmt check.
5. **No duplicated definitions** from the open list: item looks, portal link
   indexes, Add-On explosion look and sound, vehicle cameras. Each one has a
   single source.

## Tests and builds
6. **The gate is green on the PC**, with `gate-known-failures.toml` empty of
   failures. There are no flaky tests and no new `#[ignore]` or skips. Tests are
   hermetic: none reads Max's real folders. Never the 700 saves.
7. **Windows CI is green**, and the Mac and Linux release assets build.
8. **The perf headline holds** on the release build: Kitchen about 46 ms, Slate
   about 85 ms, 1M city about 9 ms, join about 0.9 s. A run no more than 5%
   worse passes.

## Release
9. **Release notes** are short player notes (Changes / Fixes plus the download
   table). The coordinator writes them and the Gate checks them against git log.
10. **Max plays it.** The packaged build goes to Max with concrete test steps.
    He decides when to publish.

## Out of scope for this release
- The single test binary per crate.
- Renderer feature passes.
- New features no lane has started.

Items 1 to 8 are what the lanes and the Gate can finish while Max sleeps.
