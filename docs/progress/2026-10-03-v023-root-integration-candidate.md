## Decisions and integration

The common rules → objective → affordances → ordinary controls → observed result
pipeline remains the bot execution path. This release adds no soccer/CTF/basketball
branches and no bot planner score/win mutation. Native object holds and charged attacks
retain commitment through temporary interruptions; repeated goals require observed
exit/reentry. Explain scopes event/NPC messages to the inspected brick.

Portal correction now carries the authoritative cumulative body and vehicle frames.
An own pose pairs the live mounted vehicle ID/frame with the rider frame at the same
tick. Vehicle history cannot be assumed equal to a new rider's history. Admission
retains its baseline across unchanged own-pose heartbeats, because own pose is sent
more often than a stationary vehicle. Control changes settle prior prediction fate
before starting the next controller. Rider crossings read live seats, not the mount
index awaiting queued dismount intents. Stale poses cannot reset spawn/camera state;
invalid frame values and future driver acknowledgments are rejected. Same-vehicle passenger→driver admission waits for a plausible current-driver acknowledgment, so a cached former-driver packet cannot poison a new controller. Alpha protocol
changed explicitly; there is no beta compatibility promise.

Copy slices recheck the existing live trust/build/paint/plant-as policy and support
revision. Native map surfaces cannot grant blocked stud attachment. Work caps cover
individual query/contact buckets and actual copying slices; these are not claims
that every world query is bounded. Face hiding uses actual opaque geometric coverage
and conservatively retains unknown/complex faces. The exact reported Octo Tree
content identity was not confirmed; renamed/sparse native mesh cases were checked.

Creator settings preserve unavailable stable IDs, protect pending drafts, and report
actual multi-step acknowledgments. Add-On choices persist in the normal user profile;
old choices discarded with an older folder are not reconstructable. Wrench Send
recolors the existing vehicle without changing its body or occupants. Existing
ownership and MiniGame policy governs Gravity Gun access to linked spawn objects.

Dynamic mode respects authored unlit materials and opaque shadow participation.
Classic/Unified appearance remains unchanged. Native avatar preview lighting and
run animation, clockwise Gravity Gun icon orientation, content-preparation-before-
admission, and admin cached-state ordering are included. Crouch dimensions already
matched the native reference; no speculative collision tuning was added.

The retained remote importer work was valuable: borrowed BLB geometry now has stable,
independent package bindings, including byte-identical meshes under distinct IDs.
Standalone death types/icons are retained. Shark finishing holds its policy identity
through canonical typed damage to avoid recapturing its own completion victim.
Only Shark/Zombie were regenerated from pinned read-only originals; the other 86
bundle entries and credits were preserved. The bundle remains a private draft.
