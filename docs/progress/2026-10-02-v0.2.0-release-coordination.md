# 2026-10-02 v0.2.0 release coordination

Maxwell authorized the coordinator thread to direct the three active threads,
review and integrate their work into main, and publish Windows, macOS and Linux
packages on GitHub. This supersedes STATUS.md's earlier Windows-only decision
for this release. It does not mark the full alpha contract or subjective
interactive acceptance complete. Maxwell remains the only interactive tester.

- Fix Lighting Doors and Addons: async reloads, role-based content fixtures,
  validated current private CI content and credited Add-On bundle.
- Polish Bot NPC World Interaction: shared capabilities, crew reservations,

- Build and run Blockland ReImagined: Rule Workshop creator tools, semantics,
  editor review fixes and headless/offscreen evidence.
- Coordinator: review, combined integration, production packaging, gates,
  release notes, platform artifact validation and publication.

Integration uses the isolated `release-v0.2.0` worktree under the approved
worktree parent; the main checkout's bot branch and files remain with its owner.
The reviewed Rule Workshop snapshot is 839390231a8a80067398eb2c04125f8bab32a078.

to the production versions. The integrated alpha uses normal per-user state.
Workshop guides are shipped on every platform with rewritten local links.

Release plan: all builds use one immutable reviewed commit. Build Windows
without public publication; stage its verified archive in a draft v0.2.0
release. Build Mac and Linux from that commit and the same manifest-verified
Windows content. Publish only after all platform checks and archive validation
pass. Platform targets remain Windows x86-64, Apple silicon macOS and Linux
x86-64; no Intel Mac or Linux ARM support is claimed.
