## Changes

- Indexed shape paths resolve from their package root, retaining containment.
  A real animated-shape regression also rejects an escaping indexed path.
- Curate ten original menu JPGs by exact path/bytes/hash. Include them in the
  sanitized source view and input identity; regenerate UI role v5. Semantic
  checks reject missing or changed reference art even if a package manifest's
  hashes are recomputed. Enforce this on content snapshot pack/fetch and all
  three platform packagers/verifiers. Original images remain generated content.
- A submitted startup GPU pixel check verifies texture upload, reversed depth,
  raster output and bounded readback, with all error scopes drained on errors.
  A clear-only negative control fails. Native presentation consistently uses
  declared unorm RGBA8/BGRA8 views, including sRGB-only storage and recovery;
  prefer compatible SDR formats over floating/10-bit HDR entries. True HDR is
  not implemented. Log device capabilities and actual compiler policy; a DLL
  beside the game cannot prove wgpu Auto's internal choice.
- Loading Map now reports actual worker task names and timings, including
  animations, world/catalog preparation, collision, map surfaces, lighting,
  verification and foliage. Counts remain intact, and task detail clears when
  the stage changes. No fake percentage or timer hides real blocking work.
- Shared package documentation now has a current-version README at root,
  optional current guides in docs/, and third-party notices under licenses/.
  Historical v0.2.x handoffs and internal creator design/test cards are omitted.
  Current player instructions and original Add-On credits remain available.
- The independent UI auditor now matches the importer's explicit recovered-text
  CRLF normalization. This changes the auditor, not original input files.
