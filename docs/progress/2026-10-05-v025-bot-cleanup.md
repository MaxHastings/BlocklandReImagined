## Simpler

- One stuck judge. The walk leg's net-progress window (`route::Progress`)
  now decides alone: first window gone nowhere hops, each later one plans
  again, and a waypoint within a step it got nowhere toward counts as
  reached. Removed the instant `stuck` counter, the `wedged` counter, the
  periodic hop and `last_position`. Swimming legs use the same judge.
- One reading of what someone is doing (`Session::seen_doing`), bots and
  people alike. A person spraying, or using any tool that does not attack,
  now reads as goofing (before: only an emote did).
- The goof gate no longer excludes Fight. Playing is worth all of itself
  against an enemy trading shots, so a goof still never wins mid-fight;
  against an enemy in sight who is goofing it is worth less, so a bot may
  goof back now and then (Max's spray-paint example), and it holds fire
  while it goofs.
- The fight-only portal check became one rule for every step: a bot steps
  into a portal only along its route; footwork, a goof or a push never
  stumbles in.
- The alarm emote's flare is an effect, not a shot (`WeaponView::fired`),
  like the spawn and death effects.
