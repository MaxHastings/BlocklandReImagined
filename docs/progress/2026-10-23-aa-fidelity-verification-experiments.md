## Observations, not completion claims

The subsequent sound-correction experiment found an axis error in the original
private audio fixture. Its claimed outdoor positive control was actually an
indoor point. The source caller/PCM facts remain valid; the positioned audio
verdict below is superseded until rerun with native `[source_y,source_z,-source_x]*.04`
and independent source/assembled partition agreement. This does not affect the
directional speed comparison, whose scalar speeds and local input axes are
independent of map coordinates.

- The installed AA2.5 directional-cap function was executed in the existing
  isolated native oracle on nine inputs. Driving the assembled soldier's actual
  tuning through the ordinary BRI motor fails six comparisons. Straight backward
  cap is 4.8 native units/s in that original function, against 7.2806 in the
  loaded motor. An isolated backward-cap-only config fixes one sample but leaves
  five failures. Existing conversion/tests shared a flagged interpretation of a
  source field. The current maximum-axis speed choice also differs on diagonals.
  This is function-level evidence, not full original movement/collision parity.
  Test existing controller velocity ownership before adding a solver/interface.
- The current assembled Pipeline mission passes ordinary rifle fire, partial
  reload, busy-fire refusal, switch interruption, ammunition conservation and
  recovery. The test records server-produced observer state. It does not prove
  network delivery, source animation timing or a rendered observer skeleton.
- Original script branch and PCM evidence plus original BSP classification
  detect an assembled output defect: the yard uses the correct outdoor rifle
  recording, while two qualified indoor views use that outdoor recording too.
  Actual emitted cues reach the production ClientAudio offline mixer with one
  finite, non-silent voice per shot. Waveform-resource tests alone miss this
  conditional routing loss. An invalid muzzle-in-solid setup was rejected and
  retained separately; source actor-region semantics still need qualification
  before implementing routing by an emission point.
- The current Interdiction cellar consumer passes its ordinary descending route.
  It does not close all human-reported underground blockers or original solver
  fidelity. Reuse the prior terrain/headroom negative-control evidence.
- Historical interpreter work is substantial and remains preserved on unmerged
  branches. Replaying its standalone native-adapter test produces green while
  reporting no pawn, movement without a collision world, unimplemented traces
  and synthetic clip lengths. Later full adapters have stronger consumers but
  were not restored/revalidated here. Neither the old green test nor a dated
  parity table establishes present playable fidelity or favors wholesale VM
  restoration. There was no comparable complete sequence on both strategies,
  so relative cost and performance remain unmeasured.

## Concrete result and limits

Two private discovery consumers and a bounded source-reference preparation/run
pair now reproduce these discrepancies against requested current engine/content
inputs. They reuse existing readers/oracles, the motor, ordinary mission Rig,
position fixture and offline client audio. Pins, input hashes, expected test
counts and required output reports are recorded; changed inputs and incomplete
experiments cannot become a pass. Private targets are removed after the run.
The comparisons intentionally return failure on the current defective behavior.

The missing-placement-fixture probe, changed-verifier probe and muzzle-in-solid
probe are retained as incomplete experiments. Early invocation outside the
engine's local cargo/toolchain context also caused redundant compilation; the
runner uses the engine working directory. These are investigator rework, not
fidelity successes. No original installation or release payload was changed.

No gameplay discrepancy was repaired or accepted by this investigation. The
improvement is automatic detection/localization of two current discrepancy
classes; audio routing was already a documented gap. There is no measured
interactive performance gain or 95% autonomy result. Required coverage remains
separate from working integrated scenarios. The broader AA/alpha goals are open.

The next bounded corrections are source-qualified acoustic policy and a complete
movement-caller comparison using existing controller mechanisms, followed by
actual two-client observation of the passing weapon sequence. Retain the working
native path and use source-derived algorithms or the preserved interpreter where
their demonstrated benefit exceeds their integration cost. No wholesale
architecture migration is justified by these results.
