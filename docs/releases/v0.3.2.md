# v0.3.2 Alpha — bug fixes and completed engine foundations

Candidate notes: not published yet. Exact candidate, required checks and package
receipts belong in the readiness/progress records before publication.

## Fixes selected for the candidate

- Namespaced Add-On maps can be selected through hosted and single-player
  Change Map confirmation. Previously their IDs were refused before loading.
- Pixel wheel gestures use logical display units, avoiding extra inventory or
  paint steps on scaled displays. Line-wheel units and direction are preserved.
- Closing Q inventory remembers the last valid tool choice through authoritative
  deselection. Removed/replaced inventory and a new connection clear stale memory.
- Dropped items at a vertical throw's apex continue falling without real support.
  Stable resting contacts, support removal, buoyancy and ordinary pickup remain
  covered by the retained tests.
- Accepted loading-screen chat typing is being restored through authoritative
  connection state, transport and HUD drawing. Include only after its final
  tests and required checks pass; do not publish this planning sentence.

The candidate also includes completed shared body fitting/socket, retained native
input and animation phase/final-pose foundations, plus trusted-host atomic native
weapon animation and loaded-round/image-state updates. These mechanisms are not
a completed Halo or AA gameplay implementation.

## Validation and limits

Root must record the exact combined gate, required Windows checks and extracted
Windows, Apple silicon macOS and Linux package verification before publishing.
No interactive gameplay is performed by agents. Published assets must contain
only the intended public/vanilla content, not private Halo/AA/GMod source assets.

ZaRR's physical Linux backend/device/scales remain unconfirmed: the demonstrated
pixel-density defect is distinguished from complete reporter revalidation.
Maxwell's intermittent hosted position pullback and subjective Blood Gulch slope
feel remain unreproduced after bounded mesh/heightfield and actual-map traces.
They are not claimed fixed.

GSF Paradise has known community-map import limits: the inspected archive lacks
the requested sand7 texture, and three authored rotating/pickable gas-station
Items require a map-item admission mechanism not included in this bug-fix release.
Fog and bloom can affect appearance, but no guessed replacement texture or shader
change is presented as original fidelity. Import reporting must describe retained
gaps honestly. These limitations do not mean the sign or original beach colour
has been restored.

Halo Chief/AR/Warthog and AA fidelity continue privately with explicit failures,
owners and consumer evidence. This release does not declare those showcases
finished. GMod remains parked.
