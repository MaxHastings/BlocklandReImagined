Blockland ReImagined v0.2.11 Alpha, a fix release on top of v0.2.10.

## Fixes
- **Beta City gunfights no longer stutter.** With 16 bots fighting on Beta City, bots worked out how far a shove would fling someone far more often than needed. That's now bounded: the slowest 5% of host ticks went from about 26 ms to about 6 ms, and the worst from 41 ms to 10 ms.
- **No freeze on the first Host.** The first Host of every run no longer freezes for about 3 seconds on its first frame: the shading pipelines are prepared while the game starts up. The first Host also no longer reloads your Add-Ons, and Single Player no longer sets up a download shelf it never uses.
- **Default builds load clean.** Loading a default build no longer opens a "Content this server does not have" box listing its stock prints (the 2x2f vent, Letters and so on) as missing. Every default build's prints and bricks were there all along. Server message boxes also keep their line breaks now.
- **Faster first Host or Join.** The game remembers its content files' fingerprints between runs, so the first Host or Join after launching no longer sits on Loading Map for about 25 seconds re-reading all 560 MB of content. A repeat load was already quick and stays that way. Hosting on LAN or the internet also lists your Add-Ons for joiners from those remembered fingerprints instead of re-reading every Add-On file.
- **UI Size between whole steps** (125%, 150%, 250% and so on) no longer makes menu text and pixel art look ragged. Strokes keep an even width at every scale, and 100%, 200% and 300% look exactly as before.
- **Free look in a vehicle:** letting go of Z now swings the view back to straight ahead instead of leaving it stuck where you were looking.
- **Bots against vehicles.** A bot that fights up close (the zombie's bite and the like) now attacks the hull of a jeep or tank an enemy is sitting in, instead of pressing against it and biting air or giving up on a rider sitting high. Bots also step out of the way of an enemy driving at them.
- **Add-Ons:** a ported Add-On ZIP (Rallypack, P90 and the like) dropped in the Add-Ons folder now shows under "Installing" (or "Could Not Install"), not "Converting", and once installed its temporary row goes away instead of staying next to the real Add-On.

## Under the hood
- The save list reads only each save's header instead of the whole file, so it opens faster with many or large saves.
- Bots find routes with less repeated work: the check that a drop or jump off a ledge is clear is now made once per route grid and remembered until a nearby brick changes, instead of once per search per bot. Routes are unchanged.
- `bri-replay <content> <recording> --bots FROM[-TO]` reads out every bot's position, health, target, plan and decisions between two moments of a recorded match (`recordmatches 1`), so odd bot behaviour can be looked at after the game.
- Releases are cut with one command (`python tools/release.py`): the Windows, Mac and Linux builds now run side by side while the release checks run, and publishing reuses those builds.

## Players on older versions
- v0.2.11 uses the same network protocol as v0.2.10, so v0.2.10 and v0.2.11 players can play together. v0.2.9 and older still cannot join.

## Download
| Platform | File | Launch |
|---|---|---|
| Windows x86-64 | `BlocklandReImagined-windows.zip` | `Launch.cmd` |
| macOS Apple silicon | `BlocklandReImagined-macos.zip` | `BlocklandReImagined.app` (ad-hoc signed) |
| Linux x86-64 | `BlocklandReImagined-linux.zip` | `./launch.sh` (glibc 2.35 or newer) |

Extract into a fresh folder. Settings and saves stay in your normal user profile. Host multiplayer by IP; internet hosting needs UDP port 28000 reachable. `SHA256SUMS` has the archive hashes.
