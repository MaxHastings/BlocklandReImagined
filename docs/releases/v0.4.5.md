# v0.4.5 Alpha

- Add-Ons can author assets and native host rules in one folder and distribute
  one ZIP. A versioned layout reuses transactional companion installation and
  one Add-On choice while preserving server-only execution, capabilities and
  separate downloadable content identity.
- New rule interfaces support NPC facing, explicit anchored locomotion,
  name-tag visibility, advisory NPC voice muting and optional quiet spawning.
  Ordinary rested bots keep their original stop-and-hold behavior.
- Camera steering has a bounded expiry lease. Animated screen images have
  authored size and backing color. Targeted presentation traffic has independent
  bounded allowances per recipient; broadcasts spend their package allowance once.
- Mounted image lights support local anchors and point-light spill. Anchors
  follow the full rendered transform, including scale. Cosmetic wrist alignment
  uses action aim with an authored turn limit, and kept off-hand devices survive
  tool switches and weapon checkpoint round trips while clearing with the body.
- Avatar artwork can be self-lit over the actual lit body paint, with a
  reversible, bounded material control. Sound stops cancel matching queued and
  active one-shots. Cross-package state reads require explicit author export.

Modders updating the interfaces proposed in PR 442 should read the
[interface adjustments](../modding/v045-migration.md) and
[co-located Add-On guide](../modding/co-located-addons.md). The separately
supplied RenderMan, flashlight and walkie Add-Ons are not new bundled content;
their exact private packages and private harness were unavailable for verification.

Hosts and guests need matching engine versions. Weapon-runtime checkpoints use
alpha schema 5; earlier weapon checkpoints are refused without migration.
Ordinary BLS import retains its existing loader. This release does not establish
full alpha acceptance or fix every retained [known issue](../KNOWN-ISSUES.md).
