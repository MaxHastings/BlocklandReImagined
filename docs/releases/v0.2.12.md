Blockland ReImagined v0.2.12 Alpha: a hotfix for two crashes, a Slayer script error and player type sounds found in v0.2.11 play.

## Fixes
- **No crash with several mirrors or windows in view.** With sun shadows on, a third mirror or window in view crashed the game on Windows and Linux. Any number of them now works.
- **No crash at launch on Linux (X11).** When the desktop briefly refused to capture the mouse as the game window opened, the game closed. It now waits a moment and tries again.
- **Slayer spawns without script errors.** In a Slayer match, some players and bots hit a script error each time they spawned, while the game set up their team outfit. Spawns now go through cleanly.
- **Player types sound like themselves.** Every body used to jump, hurt and die with the Blockhead's sounds. The horse now jumps with its own horse jump, the Add-On bots that were meant to jump silently (the Blockhead, Zombie and Shark hole bots) do, and Add-On player types with their own pain and death cries use them.

## Players on older versions
- v0.2.12 changes the network protocol to carry each player type's sounds, so everyone has to update: v0.2.11 and older players cannot join a v0.2.12 game, and v0.2.12 players cannot join theirs.

## Known issues
- An Add-On player type that brings its own sound files (rather than using one of the game's sounds) still plays the standard jump, pain or death sound. None of the bundled Add-Ons does this.
- See [KNOWN-ISSUES.md](https://github.com/MaxHastings/BlocklandReImagined/blob/v0.2.12/docs/KNOWN-ISSUES.md).

Everything else is as in [v0.2.11](https://github.com/MaxHastings/BlocklandReImagined/releases/tag/v0.2.11) (its known issues included).
