# Blockland ReImagined v0.3.1 Alpha

This release expands the engine’s support for maps, vehicles, combat feedback,
and Add-On driven game modes. It is an engine release; Halo Add-On polish is
still in progress separately.

## Maps and rendering

- Import and run map Add-Ons with authored skies, water, terrain, animated
  lights, spotlights, teleporters, and detail textures.
- Include six community maps in the bundled map set.
- Bundle all six ModTer packs, with 322 bricks and 22 terrain prints.
- Import Blender models as bricks, including concave collision shapes.
- Use authored environment reflections on materials, with separate masks and
  view-angle response.
- Tune bloom so bright emitters and terrain do not wash out the scene.
- Support textured, surface-specific bullet marks and multiplicative materials
  in both Original and modern rendering.

## Vehicles and combat

- Give vehicle cameras an orbit view and animate gunner aim, turret sway, and
  weapon bob.
- Improve vehicle steering response for both keyboard input and camera aim.
- Show live ammunition digits, per-shot lighting, vehicle shell casings,
  headlights, and impact effects that respond to the target surface.
- Let Add-Ons supply animated particle sprites, independently placed burst
  groups, and sprite casings. Pack sprite images into atlas pages so large
  effect sets preserve their artwork without exhausting texture-array layers.
- Add body footsteps and landing sounds, aim assistance, lag compensation,
  flashes, tyre skids, and lean/prone movement support.

## Game modes and interface

- Add reusable motion tracker, kill feed, chat hiding, vehicle return, death
  clips, spawn protection, and ambient sound support for Add-On game modes.
- Restore the stock Blockland HUD while using the F8 admin camera, then restore
  the active player HUD when returning to the body.
- Accept wider HUD sprite atlases with explicit decoded image and package
  memory budgets.
- Decode PCM WAV files with zero header extensions in preloaded and streamed
  playback, preserving their samples instead of leaving them silent.
- Count a legacy X11 wheel-button press/release pair once, preventing skipped
  tool slots and paint swatches on that input path.
- Size multiline tutorial completion prints to their text so the clipping
  panel no longer cuts off the final lines at the checked UI scales.

## Networking and modding

- Reduce vehicle update bandwidth for observers and correct false packet-loss
  reports and movement refusal after host stalls.
- Show joining players while they load and apply automatic admin at connect.
- Reduce server stalls from destruction, hammering and undo.
- Ship `bri-addon-check` and `bri-addon-run` with documented Rhai scripting.
  `/reloadrules` keeps rule state and retains the running script if an edit fails.
- Let rules play, stop, loop and fade music, and control cameras and trigger
  zones around physics objects.
- Add bounded host animation admission and lifetime tracking with validated
  native clip metadata. Package completion callbacks and replicated client
  playback remain future work.

Hosts and joining players must use the same v0.3.1 build because the wire
protocol changed.

This is an alpha release. Interactive acceptance and the broader alpha
definition of done remain open. See the repository’s `KNOWN-ISSUES.md` for
current limitations.
