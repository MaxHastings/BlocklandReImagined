# v0.4.7 Alpha

Legacy Add-On imports now give converted models, textures, sounds and brick
geometry readable filenames. A file like `models/StuntPlane.dts` becomes
`assets/models/stuntplane.glb`. Colliding names get a suffix derived from
the original path, so editing the file keeps its output name on reimport.

The importer still records the original path, generated path and stable
asset ID in its report. The game refreshes conversions for legacy sources
still in its Add-Ons folder. The release includes refreshed bundled Add-Ons.
See the [legacy Add-On guide](https://github.com/MaxHastings/BlocklandReImagined/blob/v0.4.7/docs/modding/old-addons.md).
