# v0.4.4 Alpha

- Improved collapsing-brick motion: detached sections retain the source blast,
  respond to observed contact and break into bounded clumps. Large collapses
  share collision work fairly across clumps and frame rates, correcting delayed
  overflow rubble without a canned base hinge or random lean.
- Improved zombie pursuit through the tested Beta16 tower, Bedroom staircase
  and mattress-house routes. Traversal respects physical launch/support
  conditions and preserves useful cross-floor searches.
- Native vehicle presentation supports authored steering animation, body grip
  nodes, wrist orientation and tool grip release. Geometry and attachments use
  the same composed body pose.
- Add-Ons can declare conditional model appearances and light switches. Cone
  geometry is shared by vehicle, mounted-image and effect lights; brake,
  reverse and jump inputs remain independent.
- Text boxes support clipboard copy, paste, cut and selection. A failed copy
  preserves the selected text instead of deleting it.
- Add-On search returns the filtered list to the top.

For modders, see [native presentation](../modding/native-presentation.md) and
[engine seams](../architecture/seams.md). The separately supplied Speedkart
update exercises these interfaces; it is not a new default bundled Add-On.
The player-made racing and bot navigation design documents describe future
work, not shipped game modes or completed mission implementations.

Alpha remains incomplete. First-use shader compilation can delay the first
map load. Bots can still pause during expensive detour planning or stall
around difficult elevated targets, narrow routes and crowds; arbitrary-height
stacking is not promised. Some legacy Add-Ons retain unsupported script or
brick-conversion reports. The reported gradual movement delay, unswung hammer
flicker, friend's server restart, RX550 black world and full v21 lighting parity
are not established as fixed by this release. Hosts and guests need matching
engine versions; alpha formats may change before beta. See
[known issues](../KNOWN-ISSUES.md).
