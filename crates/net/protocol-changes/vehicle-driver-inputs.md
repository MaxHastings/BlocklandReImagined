`VehicleView::driver_inputs` (and `VehiclePose::driver_inputs`, `VehicleSnapshot::driver_inputs`) replaces `driver_jump_held`: one byte of driver input bits, `schema::driver_input` (`JUMP` 1, `BRAKE` 2, `REVERSE` 4), replicated with the pose so every client can follow input-lit lamps. `JUMP` keeps the meaning `driver_jump_held` had (the jump input), so JumpHeld lamps are unchanged. `BRAKE` and `REVERSE` are new, for `reverse_or_brake` tail lights. Defaults 0.
