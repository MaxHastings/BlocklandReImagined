`Notice::SteerView { at, rate }`: a rule draws the player's own view toward a world point (`at`, or none to clear it); the client eases it there at `rate` degrees a second while active, recomputing the direction from its own eye each frame. Appended at the end of `Notice`.

**Addendum (round 26):** the variant gained two fields — `grip: f32` (the look-sensitivity share while the pull is active, 0.25 to 1; below 1 the holder's aim feels heavy so looking away is a struggle) and `fov_delta: f32` (a temporary FOV offset in degrees, -30 to +10; negative dollies in for a cinematic close-up). Both are temporary: they ride the pull's lifecycle and are restored by the clear (`at = None`) with it. The wire format of this variant therefore changes — `Notice` is externally tagged JSON with `deny_unknown_fields`, so old clients reject new notices and vice versa; both sides ship in one build, but a mixed-version session will drop these pulls (the client's own setter re-clamps grip to 0.25..1 and fov_delta to -30..+10 as a second safeguard). The `steer_view` script function keeps its old arities (defaults: grip 1, fov_delta 0) and gains a five-argument form `steer_view(p, [x, y, z], rate, grip, fov_delta)`.
